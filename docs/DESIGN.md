# handspan — 구현 설계 (v0.1, 2026-11-08)

AI 보조(Claude) 작성, 독립 AI 리뷰(OpenClaw)를 거친 설계 문서다. 시각 기준 시안은 공개 저장소에 포함하지 않는다.

## 목표와 범위
- 첫 공개 묶음: **감도 변환 · 감도 찾기 · 클릭 정확도 · 이동·공격 교대**, ko/en.
- 서버 없음, 로그인 없음, 광고 없음, 비용 없음. 기록은 브라우저 localStorage에만 저장한다.
- 정확성 원칙:
  - 계산값과 실측값을 구분한다.
  - 게임 계수마다 출처와 확인 날짜를 기록한다.
  - 실게임 확인 전에는 "실게임 미확인"으로 표시한다.
  - 불편감 응답은 공유 데이터에 넣지 않는다.

## 구조
```
src/
  pages/            # 페이지 템플릿 (HTML + {{key}} 자리표시자)
    index.html  convert.html  find.html  click.html  kite.html
  i18n/ko.json  i18n/en.json   # 문구. 키가 두 파일에 똑같이 있어야 빌드 통과
  data/games.json              # 게임 계수 + 출처
  assets/base.css  site.js     # 공통 (design/에서 옮김)
  assets/js/convert.js find.js click.js kite.js   # 도구별 모듈 (ES module)
  assets/js/lib/sens.js        # 순수 계산 함수 (테스트 대상)
  assets/js/lib/stats.js       # 중앙값, 구간 나누기 등 (테스트 대상)
build.mjs                      # src → dist/{ko,en}/... 생성, hreflang, sitemap.xml
test/*.test.mjs                # node --test
dist/                          # 빌드 결과 (커밋하지 않음)
```
- URL: `/ko/convert/`, `/en/convert/` 형태. 루트 `/index.html`은 언어 선택 링크와 `navigator.language` 안내만 둔다. 자동 리다이렉트는 하지 않는다.
- 빌드는 Node 22 표준 라이브러리만 쓴다. 의존성 0.

## 데이터 계약: games.json
```json
{ "id":"ow", "name":{"ko":"오버워치 2","en":"Overwatch 2"}, "yaw":0.0066, "decimals":2,
  "notes":{"ko":"","en":""},
  "sources":[{"url":"https://...", "value":0.0066, "checked":"2026-11-08"}],
  "inGameVerified":null }
```
- `sources`가 비어 있는 게임은 빌드에서 제외한다(경고 출력).
- 출처 수 표시는 `sources.length`(1곳 / 2곳+)로 한다.
- `inGameVerified`는 `{date, method}` 또는 null이다. null이면 "실게임 미확인"으로 표시한다.

## 계산 계약: lib/sens.js
- `cm360(dpi, sens, yaw)` = 914.4 / (dpi·sens·yaw)
- `sensFor(cm, dpi, yaw)` = 914.4 / (cm·dpi·yaw)
- `roundSens(v, decimals)`
- `convert(fromGame, dpi, sens, toDpi, games)` → 행 배열 `{id, sens(반올림 값), edpi(반올림 감도×toDpi), cm(반올림 감도로 다시 계산한 cm), errPct(cm 대비 오차%)}`
- `validateDpi(x)`: 100~32000. `validateSens(x)`: 0 초과 유한수. 오류 문구 키를 반환한다.
- DPI 반올림: `roundDpi(v, step)`. 최소값은 step이고, 32000을 넘으면 오류 키를 반환한다.

## 도구별 계약
- **변환**: 시안 `design/converter.html` 그대로 옮긴다. 입력은 `?g=ow&dpi=800&s=4&to=800` URL 파라미터와 동기화한다(공유 링크).
- **감도 찾기**: 아티팩트 v5 로직을 옮긴다.
  - 워밍업, ABCCBA, 플릭 20 + 트래킹 20초, 중앙값, 끝점 비율, 흔들림 추정, 불편감 제외, DPI 고정/감도 고정 모드, DPI 단위
  - pointer lock은 `unadjustedMovement`를 쓰고, 지원 여부를 표시한다.
  - 결과는 범위로 보여 준다. "측정 신뢰도"(흔들림 대비 차이)와 "계수 실게임 확인 상태"를 따로 표시한다.
  - 탭을 벗어나면(`visibilitychange`) 일시정지한다.
- **클릭 정확도**: 2D 캔버스. 목표 크기 S/M/L(반지름 14/22/32px), 움직임(멈춤/천천히 120px/s/빠르게 260px/s), 시간 30/60초.
  - 지표: 명중률, 빗나간 클릭 수, 획득 시간 중앙값, 거리 구간별(≤100, 100~200, 200~300, 300~400, 400 초과) 중앙값과 n
  - 조건이 같은 기록끼리만 localStorage에 저장하고 비교한다.
- **이동·공격 교대**: 화면에 "이동 지점"(우클릭 대상)과 "공격 목표"(좌클릭 대상)가 번갈아 나온다. 우클릭/좌클릭 매핑은 바꿀 수 있다.
  - 지표: 순서 오류, 잘못된 대상 클릭, 교대 간격 중앙값
  - 실제 게임 공격속도나 캔슬은 재현하지 않는다고 명시한다.
- 공통 결과 공유: 조건 링크 복사, 결과 이미지 저장. 이미지 저장은 canvas `toBlob` + `<a download>`로 한다(정적 사이트에서는 동작함). 불편감 응답은 넣지 않는다.

## 경계 (OpenClaw 리뷰 반영)
- **3층 분리**
  - 계산 엔진 `lib/sens.js`: 순수 함수만 둔다. DOM과 데이터에 의존하지 않는다.
  - 게임 계수와 출처: `data/games.json`
  - 표시와 반올림: 각 도구 모듈. 표시 감도로 다시 계산한 cm/360과 목표 대비 오차(%)를 함께 제공한다.
- **연습 상태 기계** (모든 연습 공통, `lib/session.js`)
  - 상태: `idle → countdown → running ⇄ paused → done`
  - 일시정지 조건:
    - Esc
    - pointer lock 해제
    - `visibilitychange`(hidden)
    - `blur`
  - 일시정지 동안은 시간을 세지 않는다. 재개하면 3초 카운트다운 뒤 이어서 진행한다.
  - 클릭 없이 끝나면 결과 대신 "기록할 클릭이 없어요"를 보여 준다.
  - 표본이 부족하면(구간 n<3, 전체 적중 <5) 해당 값을 "표본 부족"으로 표시하고 중앙값을 숨긴다.
- **기록 비교 키**: `{tool, mode, targetSize, speed, duration, arenaW×arenaH(100px 단위 구간), measureVersion}`가 모두 같아야 같은 비교 그룹이다. 다르면 다른 그룹으로 보여 준다.
- **ko/en 생성**
  - 빌드는 번역 키가 누락되거나 남는 경우 실패한다.
  - 페이지마다 `<title>`, description, `og:*`, `hreflang`(ko, en, x-default)를 둔다.
  - 언어를 바꿀 때는 현재 URL 파라미터(입력값)를 그대로 넘긴다.
- **예시 값 표기**: 시안과 데모 화면의 결과 숫자는 전부 예시다. 실제 사이트에서 결과 화면은 측정한 값만 보여 준다.

## 측정 규칙 (v2, 2026-11-08, OpenClaw 리뷰 반영)
- **시계**: 측정 시간(경과·획득 시간·트래킹 시간)은 실제 경과 시간(raw dt)으로 센다. 프레임마다 dt를 0.05초로 자르는 방식은 쓰지 않는다.
- **시뮬레이션**: 과녁 이동과 트래킹 판정은 0.02초 이하 서브스텝으로 나눠 실제 시간에 맞춘다.
- **조준 위치 (v3)**: 마우스 이동 이벤트마다 그 시각까지 타임라인을 먼저 진행한 다음 이동을 적용한다. 따라서 이벤트 사이의 조준은 마지막으로 관측한 위치이고(그동안 이동 보고가 없음), 프레임 사이를 보간하거나 추정하지 않는다. 클릭도 입력 시각까지 진행한 뒤 판정한다(`createClock`, `findRun`/`clickRun`/`kiteRun`). 같은 이동 기록을 10/30/60fps로 재생해 같은 결과가 나오는지 테스트한다. 5%p는 임시 허용치다.
- **종료 경계**: 시계와 시뮬레이션은 서브스텝마다 함께 진행하고, `session.limit`(진행 시간 또는 트래킹 길이)에서 정확히 멈춘다. 끝난 뒤의 시간은 세지도 시뮬레이션하지도 않는다.
- **멈춤 (stall)**:
  - 프레임 간격이 0.25초를 넘으면 관측할 수 없는 구간으로 본다. 0.25초는 **임시 운영 기준**이다.
  - 이때는 자동으로 일시정지한다(사유 `stall`). 진행 중이던 획득 표본(현재 목표)은 버리고, 재개 카운트다운이 끝나면 새 목표로 시작한다.
  - 경계값은 0.24초, 정확히 0.25초, 0.26초로 테스트한다.
- **후보 유효성**:
  - 설정할 수 없는 값(공통 함수의 `ok=false`, 상한 도달)은 후보로 만들지 않는다.
  - 후보는 원래 목표 cm와 실제 cm를 모두 보관한다.
  - 유효 후보가 2개 미만이거나 유효 구간이 없으면 숫자를 보정하지 않고 "추천 없음"으로 끝낸다.
- **수동 선택**: 측정상 승자가 있는 라운드(reason 없음)에서만 고를 수 있다.
- **대표값**: 적중 5개 미만이면 대표 시간(전체와 구간 중앙값)을 화면, 저장, 이미지 어디에도 내보내지 않는다.
- **조건 고정**: 비교 키(영역 크기 포함)는 시작할 때 고정한다. 진행 중 영역 크기가 바뀌면 즉시 끝내고 무효로 처리한다. 무효인 판은 저장하지 않고, 결과 이미지·링크·정상 결과 화면도 내보내지 않는다.

## 품질 기준
- 390/768/1440 너비에서 가로 스크롤 없음, 콘솔 오류 0. 탭 대상은 44px 이상이다.
- 작은 글자 대비 4.5:1 이상. 키보드로 모든 조작이 가능하다(연습 캔버스 제외, 시작/일시정지는 키보드로 가능).
- 오류는 해당 필드 아래에 표시하고 `aria-invalid`와 `aria-describedby`를 연결한다.
- `prefers-reduced-motion`에서는 장식 움직임을 끈다.
- 빌드 결과 페이지 하나당 JS 60KB 이하(압축 전).
- 문구는 taste-skill copy 규칙을 따른다. 금지어와 과장 수치를 쓰지 않고, 페이지가 스스로를 설명하는 말을 넣지 않는다.

## 단계 (OpenCode 위임 단위)
1. 뼈대 + build.mjs + i18n 검사 + games.json(10개, 출처 포함) + lib/sens.js + 테스트 + 변환 페이지
2. 감도 찾기 이식
3. 클릭 정확도
4. 이동·공격 교대
5. 홈, 메타/OG, hreflang, sitemap, 404
매 단계: Claude가 diff를 전부 읽고, 테스트와 Playwright 캡처로 확인한 뒤 커밋한다. 기능 단위로 OpenClaw 리뷰를 받는다.
